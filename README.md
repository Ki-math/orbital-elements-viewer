# 軌道6要素ビューア

軌道6要素（ケプラー要素）を、スライダーで動かしながら3Dで直感的に理解するためのブラウザアプリです。

**▶ アプリを開く：https://ki-math.github.io/orbital-elements-viewer/**

| 記号 | 名前 | 英語 | 意味 |
|---|---|---|---|
| *a* | 軌道長半径 | semi-major axis | 軌道の大きさ |
| *e* | 離心率 | eccentricity | 軌道のつぶれ具合 |
| *i* | 軌道傾斜角 | inclination | 軌道面の傾き |
| Ω | 昇交点赤経 | RAAN | どの方角に向けて傾けるか |
| ω | 近地点引数 | argument of perigee | 軌道面の中での楕円の向き |
| ν | 真近点角 | true anomaly | いま衛星がどこにいるか |

## 特徴

- **要素ごとの色分けと強調表示**：スライダーを動かすと、その要素に関係する線・角度・点だけが明るくなります
- **「形 → 面 → 向き → 位置」の組み立て順**でパネルを構成（R = R<sub>z</sub>(Ω)·R<sub>x</sub>(i)·R<sub>z</sub>(ω)）
- **視点プリセット**：斜め／北極の上／昇交点方向（*i* が真の角度で見える）／軌道面の真上（楕円・ω・ν が歪まない）
- **代表軌道のプリセット**：ISS、太陽同期、GPS、静止軌道、GTO、モルニヤ
- **再生**：ケプラー方程式で真近点角を進め、近地点で速く遠地点で遅い動きを再現
- **諸元表示**：近地点・遠地点高度、周期、速度、飛行経路角、ECI 状態ベクトル
- **用語集**：春分点、赤経、昇交点、RAAN、近点角など。カーソルを合わせると3D図の該当部分が光ります

## ローカルで動かす

ビルド不要です。`index.html` をブラウザで開くだけで動きます（three.js と Google Fonts は CDN から読み込むため、インターネット接続が必要です）。

## ファイル構成

```
index.html              画面の骨組みと用語集
css/style.css           スタイル（要素ごとの色はここで定義）
js/orbitMechanics.js    二体問題の計算（描画に依存しない純粋関数）
js/content.js           要素の説明文・スライダー範囲・プリセット
js/viewer.js            3D描画と画面の動作
```

文言やプリセットを変えたいときは `js/content.js` だけを、計算を確認したいときは `js/orbitMechanics.js` だけを見れば済むように分けています。

## 前提

- 二体問題（摂動なし）、μ = 398600.4418 km³/s²、R<sub>E</sub> = 6378.137 km
- 座標系は地心赤道慣性系（ECI）：X = 春分点方向、Z = 北極
- 描画には [three.js](https://threejs.org/) r128 を使用
